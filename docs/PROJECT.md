# 项目说明

## 产品定位
ControllerDesktop v2：面向 Windows 的手柄桌面控制与改键软件。当前免费分享，未来商业化。

## 目标用户
- 主要用户：桌面/视频/游戏间隙使用手柄控制鼠标的 Windows 用户
- 优先场景：抖音、哔哩哔哩、Steam 游戏、桌面操作
- 远期：可分享给朋友，公开仓库发布

## 必须包含
- 中英文界面
- 图形化改键
- 按程序自动切换桌面/游戏/鼠标模式
- 托盘常驻
- 安装包、卸载程序、GitHub 自动更新
- 可选驱动高级模块，单独下载、确认安装、一键卸载

## 必须排除
- 不默认安装内核驱动
- 不静默联网
- 不读取密码、Cookie、聊天记录、支付信息
- 不注入游戏进程
- 不在未确认时公开上传用户文件或配置

## 当前验收标准
本阶段先完成 v2 基础架构、中英文界面、改键配置系统、可编译项目和 GitHub 仓库。抖音驱动模块与安装包作为后续阶段。
